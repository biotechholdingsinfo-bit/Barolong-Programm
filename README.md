# Barolong-Programm

Static site containing the "Royal Barolong Nation Strategic Blueprint (2026–2051)" example pages.

What this branch does

- Adds accessibility improvements (skip link, focus outlines, responsive table wrapper).
- Adds basic SEO meta tags (description, Open Graph, JSON-LD).
- Adds README and MIT license.

How to publish

This repository can be published with GitHub Pages (Settings → Pages). Use the `main` branch (or `gh-pages`) and the root folder. If you use the `main` branch, merge the `improve/accessibility-seo` branch into it.
